# Demo Content Examples

These files are **software fixtures**, not approved industrial SOPs. They intentionally avoid gas thresholds and site-specific extinguisher/PPE rules. Codex may use them to prove the training engine, AR/3D renderer, scoring and weak-topic flow.

Before any real deployment, replace/validate them through the content-review process in `docs/22_CONTENT_AUTHORING_AND_REVIEW.md`.

The scoring examples in scenario files demonstrate engine behavior; module-level final score weighting should be defined in module configuration and tested for totals/normalization.
