# Demo assets and evidence

The supplied `../examples/demo_content` contains unvalidated software fixtures.
It is not a deployable safety curriculum or a complete demo dataset.

Seed profiles/attempts/certificates arrive with persistence and backend phases.
Do not store real worker PII, credentials or issuer private keys here.
Place small verified test summaries/screenshots in `evidence/`; generated builds
and logs go in ignored `../artifacts/`.
