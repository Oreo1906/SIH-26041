--------------------------------------------------
SCENARIO FITTING SYSTEM
--------------------------------------------------

Create or modify the existing auto-placement system so that it places a WHOLE SCENARIO rather than individual objects randomly.

Conceptual process:

AR camera starts
→ scan environment
→ gather usable ground points/planes
→ determine worker/start location
→ determine available forward/left/right space
→ test possible ScenarioRoot orientations
→ validate all important layout points
→ choose best-fitting orientation
→ create anchor(s)
→ instantiate layout
→ start scenario.

Possible orientations to test:

0°
45°
90°
135°
180°
225°
270°
315°

The exact algorithm can be simplified if the current codebase has an easier solution.

The key requirement is:

TRY TO FIT THE DESIGNED LAYOUT INTO VALID GROUND.

For each orientation:

take all critical local points:

hazard
equipment
checkpoint
entry
safe zone
etc.

Transform them into proposed world-space positions.

Raycast each location against detected ground.

Calculate a layout-fit score.

Example scoring considerations:

+ valid ground beneath required points
+ stable tracking
+ sufficient distance from camera
+ safe zone clearly separated from hazard
+ equipment accessible from worker side
+ objects not occupying exactly the same position
+ route fits inside scanned region

Reject the orientation if important points have no valid support.

Choose the best valid orientation.
